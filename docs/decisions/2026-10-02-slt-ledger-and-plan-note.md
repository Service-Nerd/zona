mechanism** — what is deliberately absent is the packaging (no flames, no notification, no urgency,
no milestone). CLAUDE.md states the product *"deliberately omits gamification — no streaks"*, so
doctrine and implementation described one object two ways. **Record corrected in both files; no
behaviour changed.** Saying "not a streak" did not make it one less.

('Heavy','Wrecked')"*, so an honest `Wrecked` loses the number while logging nothing keeps it.
→ **`LEDGER-FATIGUE-HONESTY-01`, routed to the 🏃 Coaching Board** by Hutchinson: `fatigue_tag` is an
engine input, so this degrades the data the prescription is built on. Not commercial, not design.
