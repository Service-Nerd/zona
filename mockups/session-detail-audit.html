Session detail · UX audit

The Session Detail screen says the same thing twice.

It's not that there's too much on it — it's that the same thing is on it in two places. HR and zone are rendered in three different surfaces in the top viewport. The brand-defining "Why this session" sits five blocks down, past everything execution-y. The screen needs a consolidate pass, not a redesign — kill the redundancy and the voice gets room to come back.

Working well

What's right

Five things to keep — most of these were recent ships and they landed correctly.

Keep

Zone prescription card is the right hero

HOLD-THE-ZONE-01 nailed this. Pulsing moss dot, "HOLD THE ZONE" eyebrow, 22px zone label in zone colour, HR range, labelled ZoneBar. This is the brand promise rendered visually. Don't touch it.

Keep

Sticky header pattern

44px back button, eyebrow ("Tuesday · Week 14"), 16px title, type chip right-aligned. Scrolls perfectly. No reason to change.

Keep

Provenance honesty in WHY block

WHY THIS SESSION uses <CoachByline> only when content came from the AI enricher, not when it's hand-authored DB guidance. The mark is a claim about provenance, and the screen honours that.

Keep

Auto-matched action area

When Strava has a high-confidence match, the picker demotes to "Wrong one? Pick another" and the moss CTA commits to the match. Right information architecture. Just needs visual cleanup.

Keep

Tappable Zone chip → ZoneInfoSheet

Progressive disclosure done right. The HR card's zone chip opens the full zone education sheet. Discoverable without cluttering the main view. Survives the consolidation.

Issues

What's broken

Ranked by impact. The two high-impact items together fix ~70% of the screen's problems.

Impact: high

HR / zone rendered 2–3 times in the top viewport

Prescription card shows "Zone 2 · aerobic / 127–145 bpm / ZoneBar". Metric grid directly below shows the same Zone 2 chip + the same 127–145 bpm number on its HR tile. Header chip says "EASY" (zone colour maps 1:1 to type). The user is told the same thing three different ways stacked.

Impact: high

"Why this session" is too far down

Zonna's pitch is "stops you overtraining" — the why is the brand. But on Session Detail it sits below prescription → metric grid → execution summary → What to do → Session structure → Week focus. Five execution-detail blocks before the user reaches the most brand-defining content on the screen.

Impact: medium

"What to do" and "Session structure" overlap

Description string and the R23 composer (warm-up · main · cool-down) render back-to-back for structured sessions. Same instruction in two formats. The structured composer wins on a structured session; the description string is the fallback when there's no structure.

Impact: medium

Week focus card interrupts the narrative

Sandwiched between Session structure and WHY. It's a plan-level statement ("this week is build"), not a session-level statement. Belongs on Plan/Today, not in a session card. Currently makes the WHY block feel further from the session.

Impact: medium

Action bar is too dense in auto-matched state

Primary "Log this run" + AIMark subline + "Wrong one? Pick another" + Log manually + Skip = 5 tap targets in 200px. With the sticky bar background it reads as a wall, not a primary + secondary.

Impact: medium

"How did it feel?" sits below the sticky CTA

Layout inversion. For a completed session the CTA collapses to "Update log", but the RPE scale + body feeling chips render below the action bar. The reflective state outranks the corrective action — it should be above the CTA, not banished beneath it.

Impact: medium

System B aliases linger in metric grid + execution summary

Prescription card uses 1px var(--line) + var(--card). Tiles next to it use 0.5px var(--border-col) + var(--bg). Execution summary uses var(--text-secondary), var(--amber). Side by side this reads as visual incoherence. Same kind of drift the Plan screen audit called out.

Impact: medium

No brand voice in the pre-run experience

"Hold the zone" eyebrow is the only voice anchor before the user logs the run. Then silence until the WHY block (which may be hand-authored guidance, not voice). Compare to Today's hero ("10km, slowly.") — that anchor is what makes Zonna feel like Zonna. One sentence under the prescription card closes the gap.

Impact: low

Pace caption is utility-speak

"HR-derived estimate" is technical, not brand voice. Should be either nothing or a Zonna line — e.g. "Roughly. Don't chase it."

Impact: low

Pace tile renders empty skeleton while Strava loads

A pulsing placeholder beside live data adds visual noise for a secondary metric. If pace isn't ready, render no tile — don't render an empty one.

Impact: low

Type chip splits on whitespace

typeLabel.split(' ')[0] turns "Long run" into "LONG". Loses nuance. Either show the full label (it's short) or use the canonical type-key ("EASY", "LONG", "INTERVALS") instead of slicing the display label.

Impact: low

Metric tile crams 5 elements

Distance/Duration tile holds: label · custom chip · 22px value · unit suffix · segmented selector — inside one 10px-padding card. Toggle could live behind an inline tap on the unit or under a long-press, not always-visible.

Ship order

Recommendations

Three releases, each shippable independently. Net code change across all three is mostly deletion. SLC at each step.

  1. Pass 1 — Kill the duplicate HR + add the voice. S · ~1 day Remove the HR tile from the metric grid (prescription card already owns Zone + HR + ZoneBar). Metric grid becomes Distance/Duration + Pace, 2-up. Add the voice line under the prescription card — one helper function, ~8 strings, one new component. Highest-leverage change on the screen. Closes the "same thing twice" problem AND the "no voice pre-run" problem in one ticket.
  2. Pass 2 — Reorder + simplify. M · ~2 days Move WHY THIS SESSION directly under the prescription (above structure). Suppress "What to do" when a structured composer exists (the composer wins). Remove the Week focus block from Session Detail entirely — it belongs on Plan/Today. When the session is complete, promote RPE + body feeling above the sticky CTA. Action bar collapses to 2 visible CTAs in auto-matched state. Mostly reorder + deletion, no new components.
  3. Pass 3 — Warm Slate cleanup pass. M · ~1 day Same kind of pass the Plan screen needs: replace System B aliases (var(--text-secondary), var(--border-col), 0.5px, var(--amber)) with Warm Slate equivalents (var(--ink-2), var(--line), 1px, var(--warn)) throughout the metric grid and execution summary. Drop the pace tile's "HR-derived estimate" caption. Render no tile when pace isn't ready (instead of an empty skeleton). Mechanical — visual coherence pass with no structural change.
